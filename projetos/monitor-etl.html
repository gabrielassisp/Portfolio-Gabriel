Monitor de execuções ETL

Rastreabilidade para processos Python em uma infraestrutura local.

FastAPI · SQLite · Python · HTML / CSS / JavaScript

n8n / interface → API → fila única → processo Python → SQLite + logs

O problema

Consultar o que foi executado, por qual origem e com qual resultado, sem adotar Airflow na infraestrutura disponível.

Implementação

  • Fila compartilhada entre disparos manuais e chamadas do n8n pela API.
  • Histórico persistente em SQLite com status, horários e saída do processo.
  • Consulta de logs durante a execução, timeout e solicitação de cancelamento.
  • Separação entre interface de consulta e executor dos scripts.

Decisões e limites

O executor é local e possui uma única fila. Cancelar um processo não desfaz transações já confirmadas. A interface não foi preparada como um serviço público multiusuário.

Código e demonstração

O projeto acompanha a plataforma de ETL no repositório privado. Nesta página, a arquitetura é explicativa e não contém dados de execução reais.
