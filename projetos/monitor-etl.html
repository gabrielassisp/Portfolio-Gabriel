    def submit(self, file, trigger='manual'):
        if file not in CATALOG or not (self.directory / file).is_file():
            raise ValueError('Script não permitido ou indisponível.')
        with self.lock, self.db() as db:
            if db.execute("SELECT count(*) FROM runs WHERE status IN ('queued','running')").fetchone()[0] >= 20:
                raise ValueError('A fila está cheia. Aguarde as execuções atuais.')
            ident = str(uuid.uuid4())
            try:
                db.execute('INSERT INTO runs(id,file,status,created_at,trigger) VALUES (?,?,?,?,?)',
                           (ident, file, 'queued', now(), trigger))
            except sqlite3.IntegrityError:
                raise ValueError('Este script já está na fila ou em execução.')
        self.jobs.put(ident)
        return ident

    def listing(self):
        with self.db() as db:
            rows = [dict(r) for r in db.execute('SELECT id,file,status,created_at,started_at,finished_at,returncode,trigger,note FROM runs ORDER BY created_at DESC LIMIT 200')]
            counts = dict(db.execute('SELECT status,count(*) FROM runs GROUP BY status').fetchall())
        return dict(runs=rows, counts=counts)

Rastreabilidade para processos Python em uma infraestrutura local.

FastAPI · SQLite · Python · HTML / CSS / JavaScript

n8n / interface → API → fila única → processo Python → SQLite + logs

O problema

Consultar o que foi executado, por qual origem e com qual resultado, sem adotar Airflow na infraestrutura disponível.

Implementação

  • Fila compartilhada entre disparos manuais e chamadas do n8n pela API.
  • Histórico persistente em SQLite com status, horários e saída do processo.
  • Consulta de logs durante a execução, timeout e solicitação de cancelamento.
  • Separação entre interface de consulta e executor dos scripts.

Decisões e limites

O executor é local e possui uma única fila. Cancelar um processo não desfaz transações já confirmadas. A interface não foi preparada como um serviço público multiusuário.

Código e demonstração

O projeto acompanha a plataforma de ETL no repositório privado. Nesta página, a arquitetura é explicativa e não contém dados de execução reais.
