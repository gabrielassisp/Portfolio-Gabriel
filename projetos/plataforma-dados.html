Ingestão e transformação de dados comerciais e de atendimento.

Python · PostgreSQL · dbt · Docker · n8n

APIs Zoho / Huggy / Meta → Python → Bronze → validações → dbt → Silver / Gold

O problema

Integrar fontes diferentes e organizar uma base analítica sem exigir uma plataforma de orquestração pesada.

Implementação

  • Quatro fluxos: negócios Zoho, histórico Zoho, chats Huggy e anúncios Meta.
  • Wrappers conectam a carga Python ao projeto dbt, com seletores específicos por fluxo.
  • Transformações e dependências são declaradas por source() e ref().
  • dbt executa com uma thread e em ambiente separado das dependências da API.

Decisões e limites

A consistência depende do fluxo: histórico Zoho e Meta confirmam lotes e podem deixar dados parciais após uma falha. Não há rollback global de toda a plataforma.

Código e demonstração

O código está organizado em um repositório privado. Acesso e demonstração podem ser combinados por contato.
